# A Year of Wellbeing — interactive globe

NURS 180 Wellbeing Creative Project — Ian Holzman

## Files
- `trip.js`: **all the content** (title, intro, closing, themes, stops). This is the only file you edit.
- `images/`: put your photos here and reference them in `trip.js` as `images/filename.jpg`.
- `index.html`, `style.css`, `app.js`: the site itself; no need to touch these.

## Publish on GitHub Pages
1. Create a new public repo on GitHub, e.g. `wellbeing-trip`.
2. Click **Add file → Upload files**, drag in everything from this folder (including `images/`), and commit.
3. Go to **Settings → Pages**. Under *Build and deployment*, set Source = **Deploy from a branch**, Branch = **main**, folder = **/ (root)**, then click Save.
4. After about a minute the site is live at `https://ianholzman.github.io/wellbeing-trip/`.
5. Editing later: open `trip.js` on GitHub, click the pencil icon, edit, and commit. The site updates within a minute or so.

## Preview locally
Double-click `index.html` to open it in a browser (needs an internet connection for the globe library and textures).
